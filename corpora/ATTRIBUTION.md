# Corpora: origin, derivation and licence status

## Two corpora, and only one of them comes from anywhere public

| Folder | What it is | Third-party rights |
|---|---|---|
| `public-standard/` | the 100-graph sample from Rome-Lib and the North collection, used for RQ2 (Tables 4 and 5) | yes — **not redistributed here**, see below |
| `mixed/` | 100 synthetic graphs in five families, used for the KLM-GOMS estimation and the exploratory benchmark | none, authors' own work |

## `public-standard/` is not shipped. Rebuild it.

The Graph Drawing community's dataset page states **no licence, no copyright notice and
no terms of use**, and neither archive contains a licence, readme or copyright file —
only a `Graph.log` of per-graph statistics. This was checked against the page and against
the archives themselves, not inferred. Public accessibility is not permission to
redistribute, so this package ships no graph from those collections, not even in derived
form. What it ships instead:

- `scripts/fetch_corpora.py` — downloads the archives from the source cited in the paper,
  rebuilds the sample, and verifies it.
- `scripts/bench/convert-standard.mjs` — the sampling and conversion code that produced it.
- `public-standard/index.json` — which file was selected, with its node and edge counts.
- `public-standard.sha256` — the SHA-256 of every graph file as the authors used it.

```bash
python scripts/fetch_corpora.py
```

About 5 MB of download. The script reports `100/100 graphs match the checksums recorded
by the authors`, which is what makes the rebuilt corpus the same corpus and not merely a
similar one.

The checksums are over exact bytes, so the repository carries a `.gitattributes` with
`* -text` to stop git rewriting line endings on checkout. Without it a clone on Windows
with `core.autocrlf=true` fails every checksum while the same clone on Linux passes.

### Provenance, verified rather than asserted

Every one of the 100 graphs was compared against the GraphML file it names, by node id
list and ordered edge list: identical for all 100. The archives hold 11,534 Rome and
1,277 North graphs, matching the collection sizes the manuscript's references give.

| Archive | Page label | Used as | SHA-256 (first 16) | Bytes |
|---|---|---|---|---|
| `rome-graphml.tgz` | "Undirected graphs (from the Rome graphs)" | `rome-01..50` | `94f0b300a347d485` | 4,692,225 |
| `north-graphml.tgz` | "Directed graphs (from the AT&T graphs)" | `north-01..50` | `90d37399676041b0` | 284,630 |

The canonical URLs in the manuscript (`www.graphdrawing.org/data/...`) answer HTTP 301 to
`graphdrawing.unipg.it`, which is where the files now live; the fetch script follows that
redirect. The site serves plain HTTP and its HTTPS certificate does not match the
`graphdrawing.org` name, so the checksums above, not the transport, are what authenticate
the download.

The manuscript calls the second archive "North DAGs", as the literature does, while the
page labels it "directed graphs". Both the collection's own `Graph.log` (`directed: true`
`acyclic: true` on every entry) and an independent check of the 50 sampled graphs confirm
they are acyclic, so the description holds.

## `mixed/` is synthetic throughout — including its `rome-*` and `north-*` files

All 100 graphs are generated by `scripts/bench/generate-graphs.mjs` from a seeded
`mulberry32` PRNG, 20 per family, and regenerate exactly. Three families model
architecture shapes (`layered`, `tree`, `cyclic`). **The other two, `rome` and `north`,
are imitations** calibrated to the published statistics of the public collections, written
at a time when the upstream site was unreachable; the generator's own comment says so.
They are not graphs from Rome-Lib or from the North collection, they carry no `source`
field, and a full edge-set comparison confirms that none of them occurs in
`public-standard/`.

The names are kept because the result files reference them, but nothing in this folder
may be cited as evidence about the public corpora. See INVENTORY.md finding 10 for what
this means for the paper's wording.

## How to cite the public corpora

As in the manuscript's reference list:

> Graph Drawing Community (n.d.) North DAGs: a corpus of 1,277 directed acyclic graphs
> [Data set]. http://www.graphdrawing.org/data/north-graphml.tgz
>
> Graph Drawing Community (n.d.) Rome-Lib: a corpus of 11,534 undirected graphs
> [Data set]. http://www.graphdrawing.org/data/rome-graphml.tgz

The collection sizes in those entries were confirmed against the archives: 11,534 and
1,277 GraphML files respectively.
