# Licensing

This repository holds two kinds of material under two different licences, and it also
*refers to* third-party data that it does not contain and cannot license.

## Scripts — MIT

Everything under `scripts/` is licensed under the MIT License; see
[LICENSE-MIT](LICENSE-MIT). That covers `scripts/fetch_corpora.py`,
`scripts/analysis/*.py` and `scripts/bench/*.mjs`.

`scripts/bench/package.json` and `scripts/bench/package-lock.json` only declare
dependencies. The dependencies themselves are not distributed here and keep their own
licences; `npm install` fetches them.

## Data and documentation — CC BY 4.0

Everything else that originates with the authors is licensed under the Creative Commons
Attribution 4.0 International License; see [LICENSE-CC-BY-4.0](LICENSE-CC-BY-4.0). That
covers:

- `data/` — the benchmark results, KLM-GOMS estimates, anonymised SUS responses, expert
  ratings, field times and AS-IS/TO-BE measurements
- `corpora/mixed/` — the 100 synthetic graphs, which are generated by
  `scripts/bench/generate-graphs.mjs` and are the authors' own work
- `corpora/*.sha256` and `corpora/public-standard/index.json` — the manifests
- `protocols/` — the validation plan, instruments and certification template
- all Markdown documentation, this file included

Attribution means citing the article this package accompanies:

> Horna Silva FE, Liñian Sanchez FE, Zarate Bocanegra JA. Automatic layout of software
> architecture diagrams with the Sugiyama algorithm: an empirical study in industry.

## Third-party graph data — not included, not licensed here

The Rome-Lib and North collections are distributed by the Graph Drawing community
**without a licence or terms of use**. Neither licence above applies to them, and no
graph from either collection is included in this repository, not even in derived form.
`scripts/fetch_corpora.py` downloads them from their original source at run time and
rebuilds the sample locally; `corpora/public-standard/index.json` records only which
source file each sampled graph came from, with its node and edge counts.

See [corpora/ATTRIBUTION.md](corpora/ATTRIBUTION.md) for the full provenance account and
for how to cite the collections.

## What is not here

The AlphaGraph application's own source code is not part of this repository. The benchmark
harness in `scripts/bench/` implements the AlphaGraph layout condition itself, on top of
the open-source dagre library, so the comparison can be re-executed without it.
